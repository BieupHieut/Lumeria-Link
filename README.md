# Lumerian Link

## English

**Your captured moments, connected to your Android device.**

Lumerian Link connects a LUMIX camera to an Android phone or tablet over USB. Transfer original photos, preview new shots, and check camera usage information in one app.

### Features

- Automatically save original RAW/JPG files.
- Select RAW + JPG, RAW, JPG, or OFF.
- Preview newly captured photos in portrait, landscape, or full screen.
- Check shutter count, power/wake count, additional counters, and serial number on supported cameras.
- Continue transfers in the background and while the screen is off, depending on device settings.
- Keep your settings between sessions.
- Use Korean, English, Spanish, or Japanese.

### Download

Open this repository’s **Releases** page and download the latest APK from **Assets**.

Illustrated installation and app introduction guides are available as separate images.

### Quick start

1. Install Lumerian Link.
2. Connect your camera using a USB data cable.
3. Select **PC(Tether)** on the camera where available.
4. Open the app and start the connection.
5. Choose a transfer format and take a photo.

For Galaxy background and screen-off transfers, set:
**Settings → Apps → Lumerian Link → Battery → Unrestricted**

### Compatibility

- Android 7.0 or later, with a compatible 64-bit ARM device and USB host support.
- USB transfer tested with **LUMIX DC-S1RM2 / firmware 1.5**.
- Connection modes, RAW formats, and camera information support vary by model.
- PC-tool counter validation and Android photo-transfer validation are separate records.
- Preview displays captured photos; sensor live view is not included.

### Installation notes

Galaxy Auto Blocker may prevent APK installation. Temporarily disable it when needed and re-enable it after installation.

If prompted, allow installation from the app used to open the APK. If Play Protect offers an app scan, run it. If the warning specifically says the app was built for an older Android version, select **Install anyway** to continue. The installation guide illustrates this warning.

## 한국어

**촬영한 순간을 스마트폰으로.**

Lumerian Link는 LUMIX 카메라와 Android 스마트폰·태블릿을 USB로 연결하는 앱입니다. 원본 사진 전송, 새로 촬영한 사진 미리보기, 카메라 사용 정보 조회를 한곳에서 제공합니다.

### 주요 기능

- RAW/JPG 원본 자동 저장
- RAW + JPG / RAW / JPG / OFF 선택
- 가로·세로 및 전체 화면 촬영 후 미리보기
- 지원 카메라의 셔터수·전원/깨우기·추가 카운터·시리얼 번호 조회
- 기기 설정에 따른 백그라운드·화면 OFF 전송
- 재실행 후에도 설정 유지
- 한국어·영어·스페인어·일본어 지원

### 다운로드

이 저장소의 **Releases**에서 최신 버전을 열고 **Assets**의 APK를 다운로드하세요.

APK 설치 안내와 앱 소개는 별도 이미지로도 제공됩니다.

### 빠른 시작

1. Lumerian Link를 설치합니다.
2. USB 데이터 케이블로 카메라를 연결합니다.
3. 카메라에서 지원되는 경우 **PC(Tether)**를 선택합니다.
4. 앱을 실행하고 연결을 시작합니다.
5. 전송 형식을 선택한 뒤 사진을 촬영합니다.

갤럭시에서 백그라운드·화면 OFF 전송을 사용하려면 다음과 같이 설정하세요.
**설정 → 애플리케이션 → Lumerian Link → 배터리 → 제한 없음**

### 호환성

- Android 7.0 이상, 호환되는 64비트 ARM 기기 및 USB 호스트 지원 필요
- **LUMIX DC-S1RM2 / 펌웨어 1.5**에서 USB 전송 시험
- 연결 모드·RAW 형식·카메라 정보 지원은 기종에 따라 다름
- PC 도구의 카운터 검증과 Android 사진 전송 검증은 별도 기록
- 미리보기는 촬영한 사진을 표시하며, 센서 실시간 라이브뷰는 포함하지 않음
